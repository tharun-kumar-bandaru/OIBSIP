# Task 3: Data Cleaning

## Objectives

- Identify and handle missing values
- Detect and remove duplicate records
- Standardize inconsistent values
- Correct data types
- Standardize date formats
- Detect and handle outliers
- Compare data quality before and after cleaning
- Export the cleaned dataset

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Data Cleaning Performed

- Missing values were analyzed and appropriately treated.
- Duplicate records were identified and removed.
- Text and categorical values were standardized.
- Date values were converted to datetime format.
- Numerical columns were converted to appropriate data types.
- Potential outliers were identified using the IQR method.
- Invalid values were identified and handled.
- A before-vs-after data quality comparison was performed.

## Final Output

The cleaned dataset was exported as a CSV file and is ready for further analysis.
