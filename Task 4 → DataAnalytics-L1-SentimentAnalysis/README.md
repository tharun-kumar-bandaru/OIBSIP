# Task 4 – Sentiment Analysis

## Objective

Build a machine learning model to classify movie reviews as positive or negative using Natural Language Processing and machine learning techniques.

## Dataset

IMDb Movie Reviews Dataset containing positive and negative movie reviews.

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- WordCloud
- Jupyter Notebook

## NLP Preprocessing

- Lowercase conversion
- HTML tag removal
- Punctuation removal
- Number removal
- Tokenization
- Stopword removal
- TF-IDF vectorization

## Machine Learning Models

1. Multinomial Naive Bayes
2. Logistic Regression

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Visualizations

- Sentiment Distribution
- Positive Reviews WordCloud
- Negative Reviews WordCloud
- Model Performance Comparison
- Confusion Matrices

## Error Analysis

Five misclassified reviews were examined to understand model limitations such as sarcasm, negation, mixed sentiment and contextual language.

## Real-World Applications

The sentiment analysis system can be applied to customer feedback, product reviews, social media monitoring, movie reviews, surveys and customer support analysis.

## Conclusion

The two machine learning models were compared using multiple evaluation metrics. The model achieving the highest F1-score was considered the best-performing classifier for this sentiment analysis task.
